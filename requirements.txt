# INFERENCE RUNTIME — choose ONE of the options below:
#
#   Option A — CPU only (default, works everywhere):
#     pip install onnxruntime
#
#   Option B — Intel Iris Xe / AMD iGPU / any DirectML GPU on Windows
#              (recommended for the doctor's Lenovo IdeaPad i5-1135G7):
#     pip install onnxruntime-directml
#
#   Option C — Intel CPU + iGPU together via OpenVINO (highest throughput
#              on Intel hardware, uses CPU and iGPU simultaneously):
#     pip install onnxruntime-openvino
#
#   Option D — NVIDIA discrete GPU:
#     pip install onnxruntime-gpu
#     (also reinstall torch with CUDA: see https://pytorch.org/get-started)
#
#   The app auto-detects which runtime is installed and picks the best
#   available provider. Falling back to CPU if no GPU runtime is found.
